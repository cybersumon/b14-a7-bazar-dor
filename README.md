# Bazar Dor

Bazar Dor is a web application that tracks product prices on a daily basis. The application is created with Next.js. You will be able to search for product prices, compare market prices, filter products based on categories, and get more information on products.

## Technologies

- Next.js 16
- TypeScript
- Tailwind CSS
- Better Auth
- MongoDB
- Sonner

## Features

- Tracking of product prices on a daily basis
- Browsing of products category-wise
- Sorting of prices from low to high and vice versa
- Product details with prices per market
- Email and password-based authentication
- Google and GitHub authentication
- Protected product details page
- User profile to change name
- Responsive design
- Toast notifications

## Authentication

Authentication can be done via:

- Email and password
- Google
- GitHub
